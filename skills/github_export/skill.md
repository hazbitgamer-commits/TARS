# github_export
Packages the non-personal parts of TARS -- the engine code (brain.py, neuro.py,
skills_engine.py, main.py, ...), every skill's skill.py/skill.md, and the
dashboard HTML/JS/CSS -- into `workshop/github_export/`, ready for Jacob to
upload to GitHub himself. Leaves out anything personal or private: the vault,
faces, logs, conversation transcripts, the learned brain memory files
(brain_neurons.json, brain_synapses.json, brain_vectors.npy,
brain_activity.jsonl), and every credential/token/settings file. TARS never
uploads or sends the folder anywhere -- it only prepares a clean local copy.

**Say:** "which part of you can I upload to GitHub" / "package your brain
design for GitHub" / "make me a GitHub-ready copy of yourself"

**Args:** none.
