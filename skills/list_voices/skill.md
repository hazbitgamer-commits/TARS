# list_voices
Reads out the text-to-speech voices TARS can speak with, and names whichever
one is currently active (checked live from tts.py / voice_settings.json).
Read-only — doesn't change anything.

**Say:** "list your voices" / "what voices do you have" / "what voices can you use"

**Args:** none.

Different from:
- `voice_settings` — actually changes the active voice or talking speed.
- `voice_output` — which PC speaker/device TARS's voice plays through.
