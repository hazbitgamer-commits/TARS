# creator_identity
Answers questions about who made, built, or created TARS. A purely informational meta skill — it doesn't touch any files, install anything, or send anything anywhere. It just confirms, out loud, that Jacob built TARS.
**Say:** "Jacob made you" / "who made you" / "who created you" / "who built you"
**Args:** `statement` — optional, the phrase Jacob said (not required to form the answer).
