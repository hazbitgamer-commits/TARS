# open_app
Opens an application or website. If the name isn't an exact match, it searches
every installed program (Start Menu + Microsoft Store apps) for one that
resembles what you said and opens the closest match — e.g. "open obsidian"
finds and launches Obsidian even without a hardcoded alias for it.
**Say:** "open chrome" / "open spotify" / "open obsidian" / "open youtube dot com"
**Args:** `target` — app name, folder name, or website address.
