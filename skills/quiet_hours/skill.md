# quiet_hours
Remembers a "no technology" schedule for the house (e.g. 8 PM to 7 AM) and can tell you whether it's active right now.
**Say:** "add quiet hours for no technology from 8 o'clock to 7 a.m." / "what are quiet hours" / "are we in quiet hours right now"
**Args:** `action` — set/status (default: set if times given, else status). `start` — start time like "8pm". `end` — end time like "7am".
Note: this only tracks and reports the schedule — it doesn't switch off any devices itself.
