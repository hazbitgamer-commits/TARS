# object_detection
TARS names the objects the desk webcam can see right now (people, cars, animals, furniture, everyday items) using a small local SSD MobileNet-v1 model (COCO classes), run through onnxruntime. Fully local — nothing leaves the PC. Model file: `ssd_mobilenet_v1_10.onnx` (downloaded once from the ONNX Model Zoo, lives in this folder).
**Say:** "what objects do you see" / "detect objects" / "what's in front of the camera"
**Args:** none.
