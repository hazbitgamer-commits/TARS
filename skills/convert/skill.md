# convert
Offline unit maths (length/mass/volume/speed/data/temperature), live currency via frankfurter.app (no key), world clocks via zoneinfo. Returns __PASS__ when it is not really a conversion so the brain answers normally.
**Say:** "how many km in 5 miles" / "50 US dollars in Aussie dollars" / "what time is it in London"
**Args:** `query`.
