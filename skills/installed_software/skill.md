# installed_software
Lists installed programs (from the same registry Add/Remove Programs reads),
or checks whether a specific one is installed — handy for "not found" mix-ups
like cadm.
**Say:** "what's installed on this PC", "is cadm installed", "do I have Python installed", "list installed programs"
**Args:** `name` (optional) — part of a program's name to check for; blank lists everything.
