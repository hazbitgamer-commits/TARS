# vacuum_speed
SELF-TAUGHT by TARS. Sets the eufy robot vacuum's suction/fan speed (quiet/medium/hard/max), separate from starting or docking it. Uses the shared eufy_vac.py link (same account/quiet-hours setup as the vacuum skill); added `set_fan_speed()` there.
**Say:** "make the vacuum quiet" / "set clean mode to medium" / "battle clean mode hard clean" / "turn the vacuum to max"
**Args:** `speed` — quiet / medium (standard) / hard (loud, turbo) / max.
